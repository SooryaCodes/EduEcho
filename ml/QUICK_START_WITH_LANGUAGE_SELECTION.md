# Quick Start Guide - With Language Selection

## 🚀 How to Use the App (Updated)

### Step 1: Upload & Transcribe

1. **Upload audio file** (MP3, WAV, M4A, etc.)
   
2. **Select input language** (NEW!)
   - **Auto-Detect** (default) - Let the app figure it out
   - **OR** Choose specific language from 28 options
   
3. **Click "Transcribe Audio"**

4. **Wait for transcription**
   - First time: ~5-10 minutes (downloads model)
   - After: ~5-10 seconds

5. **View transcribed text** with language badge

### Step 2: Translate

1. **Select target language** (Hindi, English, Tamil, etc.)

2. **Click "Translate"**

3. **Wait for translation**
   - First time: ~10-15 minutes (downloads model)
   - After: ~2-5 seconds

4. **View translated text**

### Done! 🎉

---

## 🎯 When to Use Auto-Detect vs Manual

### Use Auto-Detect When:
- ✅ You're not sure what language is in the audio
- ✅ Audio might have mixed languages
- ✅ You want convenience (zero effort)
- ✅ Testing or exploring

### Use Manual Selection When:
- ✅ You know exactly what language it is
- ✅ You want maximum accuracy
- ✅ Audio has heavy accent or background noise
- ✅ Auto-detect keeps getting it wrong

## 💡 Tips

### For Best Transcription:
- ✅ Use clear audio (minimal background noise)
- ✅ Select the correct language manually if you know it
- ✅ Use good quality audio files (not too compressed)
- ✅ Keep files under 10 minutes for faster processing

### For Best Translation:
- ✅ Ensure transcription is accurate first
- ✅ Short sentences translate better than long ones
- ✅ Technical terms might not translate perfectly
- ✅ Review and edit if needed

## 🔍 Understanding the Badges

### In Transcription Results:

**"Auto-detected: HI"**
- App figured out the language automatically
- Might be from Whisper or script analysis

**"Language: HI"**
- You manually selected Hindi
- Transcription optimized for Hindi

## ⚙️ First-Time Setup

### First Run:
1. Open the app
2. Upload any audio file
3. Select language (or use auto-detect)
4. Click Transcribe
5. **Wait 5-10 minutes** - Downloading Whisper model (~142MB)
6. Transcription completes
7. Select target language
8. Click Translate
9. **Wait 10-15 minutes** - Downloading translation model (~600MB)
10. Translation completes

**Total download: ~742MB** (one-time only)

### Every Other Run:
- Transcription: **5-10 seconds**
- Translation: **2-5 seconds**
- Models cached in browser! ✅

## 🆘 Troubleshooting

### "Language detection seems wrong"
→ Use **manual selection** instead of auto-detect

### "Transcription is inaccurate"
→ Try **selecting the specific language** manually

### "Translation failed"
→ Check if transcription succeeded first

### "Models taking forever to load"
→ Normal on first use! Subsequent runs are fast

### "App is slow"
→ Clear browser cache and reload
→ Or use a modern browser (Chrome, Edge, Firefox)
